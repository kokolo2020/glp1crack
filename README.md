# GLP-1 Protein Calculator

A simple Next.js + Tailwind CSS calculator website for GLP-1 users.

## Features

- Protein target calculator
- Water intake estimate
- Calorie estimate
- BMI calculation
- Muscle preservation score
- Mobile responsive landing page
- SEO metadata included

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy

Push this folder to GitHub, then import the repo into Vercel.
